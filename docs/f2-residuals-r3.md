# F2 输入版本与数值边界

本页保留可公开的方法和结论。逐证券、逐日期的真实参考值、派生对照、财报金额及原始证据仅保存在本地忽略目录，不随源码或发行包公开。

## 财务输入版本

有限原题中，公开财报的原始披露版本与后来取得的供应商快照存在金额差异。替换为经独立核对的原报告输入，可以解释对应财务比率的部分偏差；这属于事后输入敏感性分析，不能追认为新的前瞻验收。

现金利润比仍使用单季经营现金流净额除以单季归母净利润；累计差分、报告期一致性和缺失传播规则不变。不能以全部净利润、年度累计或其他口径代替。明确传入的 FinancialPIT 版本包缺项时，不回退到另一快照。

公告当日仅有日期而无精确时刻时，研究读取沿用次日可见约定。当前捕获的原始附件不能证明历史首次可得时刻、历史附件字节身份或完整修订链，严格模式仍可能返回 visibility_unproven。

## 行情与剩余误差

独立行情来源、显式复权控制及窗口检查并未完全解释价格因子残差。共同正比例缩放不会改变相关比值，但不能据此推断因子服务的内部行情版本或预处理规则。未通过原阈值的题目继续保留失败状态，不通过标签拟合、精度网格或统一舍入制造一致。

## 验收状态与使用

原冻结验收仍为 **244/252**；**248/252 仅属四格原报替换后的事后敏感性**。剩余三格 BIAS5 和一格 CCI20 的原因尚未闭环。计数是验证范围说明，不提供原始或派生行情值。
