# 0.2.0rc2 复核修正

0.2.0rc1 独立复核发现一项缓存闭合问题和两项隔离/分类问题。本候选仅修正这些问题、补充边界测试并更新版本及说明；真实源、字段默认值、单位、缓存模式及依赖版本不变。尚待独立增量复核。

| 问题 | 修正 | 复验 |
|---|---|---|
| 盘中日线缓存随查询时钟推进被升级 | 闭合限时受响应观测时刻约束；新响应另记请求开始，跨边界请求取较早时刻。旧缓存以已有观测时刻兼容读取 | 14:00→16:00、隔夜、only/长TTL prefer、1m/5m、精确边界、在途跨边界、旧缓存，以及刷新后新值 |
| 非空错误 JSON 被误报无数据 | 仅 null/空数组报 SOURCE_NO_DATA；错误对象及其他 JSON 类型报 SOURCE_SCHEMA_ERROR，并给 response_kind | 错误对象、字符串、数字、布尔、空对象均不缓存；null/空数组保留明确无数据语义 |
| 修改 capabilities 返回值污染解析配置 | default_fields 返回副本；其余列表仍为每次新建 | 修改能力列表后，后续能力输出和正常取数均保持原配置 |

作者实际复跑：153项项目测试（原126+新增27）及原样独立反例13项，共166通过、0失败、0跳过；ruff通过。独立文件本轮未改动，也未将作者复跑称为新的独立验收。

仍不保证完整历史、PIT、复权、停牌或聚宽14:55语义等价。缓存闭合修正只约束软件对已取得响应的使用，不把抓取时间当作历史 available_at。
