# 行动审阅范围扩展

原13/14日及14/15日基线保持原解释。后续有限范围通过外置 `review.json` 与原始响应单独封存，
使用 `ASHARE_ACTION_EXTENSION` 和 `ASHARE_ACTION_EXTENSION_SHA256` 同时显式选择。
旧证据族仍由 `ASHARE_PILOT_EVIDENCE` 指定。所有真实公告、附件和审阅原件留在本地证据目录，
不进入 Git、wheel 或源码包。

扩展验证固定旧基线、范围端点的交易所日历、完整公告目录和已审阅正文的本次实际复读。
旧公告不得缺失、修订或变更主体。新增公告默认拒绝；若完整正文及附件经明确人工审阅为
仅公司治理事项，可将逐份说明加入 `reviewed_additions`。该路径不接受新的现金分配、
股数转换、价格调整或代码变更；这些需要相应行动处理能力和另行审阅。

范围最多31个日历日，开始日继承原账户审阅范围。周末不需要人为加一天；交易日仍由每日行情日历控制。
范围授权不代表预知未来没有公司行动。每次盘中准入和执行均重取完整目录、全部已审阅正文、
分红表、身份、风险和交易状态；新增或变更披露会重新阻断。缺失选项、错误摘要、旧回执、
漏页及无效日历不会放行。

`load_baseline(replan=True, extension=False)` 可以核对固定旧基线，不受新选择影响。
`baseline_identity(replan=True)` 返回实际选择的审阅摘要，AQ 必须将其与 AD 源码摘要一起封存到新绑定。
已有原始报文应使用其原冻结读端及原选择重读，不用新审阅结论覆盖历史。

`tests/test_action_extension.py` 使用自写合成材料验证范围、来源完整性、旧解释、拒绝规则和新增治理公告审阅。
测试不下载数据，不提供生产绕过固定原基线摘要的入口。
