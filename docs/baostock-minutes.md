# BaoStock 有界分钟接口候选（0.5.0.dev2）

基于冻结日线版本 `6b0a24ad4719657410f7621cf42ade41c93a6d21`；本轮独立分支，日线候选不改写。

| 调用 | 契约 |
|---|---|
| `source.get_price(security, store=..., start_date=..., end_date=..., frequency="5m")` | 仅5m/15m/30m/60m；一个显式沪深证券、最多连续2个自然日。正常匿名免费源直接查询并封存，返回ResearchResult。默认daily保持原行为。 |
| `source.fetch(store, kind="minute", ..., frequency="15m")` | 返回含原文与请求回执的固定capture_id；失败也保留证据。 |
| `Store(root).baostock(capture_id).get_price()` | 无SDK/无网络重开固定分钟版本；数据、请求证券/周期/日期、原文hash及字段身份重验。 |
| `view.coverage()` | 按“标签落在上午/下午交易时段结束网格”的假设报告实测标签、缺口、午休及收盘位置。假设网格符合不等于市场完整覆盖或闭合语义已认证。 |
| `baostock-fetch minute --frequency 30m` / `baostock-query price --capture ...` | 显式采集和离线读取。1m在请求前报错，不降级、不换周期。 |

源字段：`date,time,code,open,high,low,close,volume,amount,adjustflag`；time保留原始17位字符串，规范DataFrame索引为Asia/Shanghai语义的源时间标签，数值不平移。为避免列名与time索引同名，原始time另保留为`source_time`及`source_row.time`。

价格Decimal元/股，volume整数股，amount Decimal元；原价flag3，不聚合日线，不补缺口、不丢弃差异。验证日期与时间一致、证券/周期/窗口身份、排序/去重、OHLC与有限非负量额。bar_start、bar_end、available_at仍为空；“结束标签”只作有明确标识的推断，不能据此宣称14:55已闭合。

本轮先实测少数证券1个交易日各周期；不引用SDK广告范围冒充覆盖。不支持1m、历史PIT、完整历史或严格交易准入。压缩96帧外层校验未知继续维持研究限制；无历史可见性证据不妨碍显式研究读取。

## 本轮实际采集结果

仅通过现有官方0.9.4 SDK正常匿名入口串行查询，共6次业务请求：5次分钟、1次日线对照；无重试/换源、无新服务或密钥。

| 证券/日期 | 周期 | 实际行数 | 首/末标签 |
|---|---|---:|---|
| 600000.XSHG / 2026-09-30 | 5m | 48 | 09:35 / 15:00 |
| 同证券同日 | 15m | 16 | 09:45 / 15:00 |
| 同证券同日 | 30m | 8 | 10:00 / 15:00 |
| 同证券同日 | 60m | 4 | 10:30 / 15:00 |
| 000001.XSHE / 2026-09-29～09-30 | 5m | 96 | 每日09:35 / 15:00 |

合计172个分钟源记录，只有上述证券/日期/周期的实测证据；不得外推全市场、过去数年或任意日期覆盖。各观测日标签包含11:30与15:00，11:30至13:00午休内无标签，与结束标签假设网格一致。没有把这个一致性提升为逐笔聚合口径或实际发布时间验证。

量额对照保留原差异：浦发2026-09-30各分钟周期成交量合计均为147484820股，与既有固定日线相同；分钟成交额合计1386209937.0000元，日线1386209937.3800元，差-0.3800元，未进行四舍五入修正或替换。平安上述两天5分钟合计与新取同源日线量额一致；仍不能凭合计相同证明完整性/可交易性。

真实请求均返回成功，没有观察到远端网络或权限失败。部分响应、SDK行不一致、错误证券/周期/日期、非法OHLC/量额等为明确标注的合成故障注入；与真实数据目录分开。

首轮回归捕获Python `strptime` 对紧凑数字的可变宽度解析风险，现改为严格按17位字段切片构造时间；非法小时25拒绝，毫秒原样保留。

## 版本与兼容

分钟清单版本为 `baostock-research-2/receipt-4.1`；已有日线/资料/日历清单保持`baostock-research-1/receipt-4.1`。新读者支持两者，周期与清单版本必须匹配，不重写已有capture或升级其时间/质量证据。解析器、SDK装载器、登录及分页/回执模块延续冻结日线实现。

只按已请求频率验证返回行的身份，不把5m自动聚合成15m/30m/60m，也不降级为更粗周期。网格假设之外的合法时间标签仍保留，并列入`outside_hypothesized_grid`；缺口/日期无行明确报告，不把空响应解释为无交易事件。
