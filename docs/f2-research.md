## 定义与输入

| 字段 | 冻结公式 | 数据理由与限制 |
| --- | --- | --- |
| `BIAS5` | `(收盘/5日均价-1)×100` | 独立原始价×新浪当日有效累计因子；共同正比例缩放不影响比值 |
| `CCI20` | `(TP末值-TP均值)/(0.015×TP平均绝对偏差)`，TP=(高+低+收)/3 | 20个连续交易日；偏差为0返回缺失 |
| `PSY` | 12次变动中严格上涨次数/12×100 | 13个收盘价；平盘不计上涨 |
| `quick_ratio` | `(流动资产-存货)/流动负债` | 东方财富合并资产负债表，当前/非当前分类适用的非金融发行人 |
| `debt_to_asset_ratio` | `总负债/总资产` | 同一最新可见报告；单位为比值，不乘100 |
| `net_operating_cash_flow_coverage` | `单季经营现金流净额/单季归母净利润` | Q1直接，Q2–Q4累计差分；不是合并净利润或TTM；负分母保留且标记 |

主要定义来自已留存的[聚宽官方主因子目录](https://www.joinquant.com/help/api/help#name:factor_values)，
2026-10-11采集，SHA256 `f8078eb107e090a545b915dac90651b3d62f3b171e3fdaf43adced8d1e2516db`。
目录的单季默认规则和条目说明一并保留；SDK `technical_analysis` 不代替主因子实现。
当前公开页面区域受限，没有借登录浏览器绕过。公式名相同不构成内部实现一致的证明。

行情使用精确十进制输入和有理数运算，最终输出50位有效数字字符串；没有价格量化、递归种子或
绝对复权锚拟合。新浪/腾讯原始OHLC是两次独立来源读取，但复权因子共同取自新浪，
不能把双源一致扩大为复权制度独立确认。未取得聚宽参考值，所有 `jq_equivalent=false`。

## 调用

数据不随wheel分发。解开配套证据包后：

```python
from ashare_data import FactorResearchView
from ashare_data.f2 import DEFINITION, MODE

view = FactorResearchView.from_file(
    "evidence/derived/dataset.json",
    evidence_root="evidence",
    expected_sha256="585ceffc8d1197a1b232f6df2b210145dbaf93bb59a8fa7ef96b3181226bacad",
)
result = view.query(
    ["600519.XSHG", "300124.XSHE"],
    ["BIAS5", "CCI20", "PSY", "quick_ratio", "debt_to_asset_ratio",
     "net_operating_cash_flow_coverage"],
    dates=["2024-05-06"], definition=DEFINITION, mode=MODE,
)
```

`query` 返回证券×日期×字段完整网格，`value` 为十进制字符串或None，`status` 为`ok/missing`。
合法但无资料的证券、缺交易日/预热、无有效复权因子、零分母、未披露报告、缺前一累计项、
现金与利润最新报告期不一致均明确缺失；不补齐、不压缩交易日、不退到旧报告。
非法证券格式、重复项、错误OHLC/单位/财务符号和不支持的模式直接报错。
金融指标按上海日期开始时评估，只取`notice_date < date`；当日仅有日期的公告不纳入。
价格因子包括所选日期收盘价，信号不得用于当日收盘前的交易。

`from_file`校验输入投影及每个原始文件的哈希/大小和路径边界；这只核验字节一致性，
不认证供应商身份、来源正确性或历史可见性。直接构造`FactorResearchView(dataset)`不标记文件已验证。

可传`financial_pit=FinancialPIT(...)`，仅把现金利润比的输入切换为已有版本账本的
`net_operate_cash_flow`和`parent_net_profit`单季查询；返回逐项谱系及档案哈希验证状态。
账本缺项时不回退到快照。资产负债表两项仍是快照模式；没有扩大FinancialPIT字段或时点认证。
PIT独有证券无需在行情/快照输入中添加占位项；混合字段查询中，缺少该证券快照的行情和
资产负债表字段仍返回缺失，现金利润比独立使用PIT账本。
真实适配测试使用普利制药2024Q1的延期首次披露：原预约日、法定截止日、董事会日及
2024-07-05披露当日均不释放数值，07-06起可用。该期记录没有替代链，
不能支持原值被更正值替换的验收；F2现金利润比的真实修订链仍未验证。
