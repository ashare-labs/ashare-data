## SV02 两种结论并列

冻结路径为四位亿元量化 `q` → binary64 → 乘 `S=10^8`。SV02 返回仍带 `candidate_status="failed_round14_named_key_zero_ULP_rule_preserved"`，没有更换算法或事后取整。

对该正常有限数值，单位转换误差界由独立 `q` 与运算次序推导：

`B = S × ½ ULP(fl(q)) + ½ ULP(fl(fl(q) × S))`

固定键的误差界、原差与逐值复算留在本地；原差在独立推导的界内。此处只解释四位亿元量化之后的二次浮点舍入，不能把原价乘股数到四位亿元的量化差、错误单位或错误版本混入这个界。数值等价不意味着逐位通过，也不证明供应商采用某一种内部转换顺序。

`observe_fi_sv_batch` 继续按原预锁 11 键、顺序、授权时间、dtype、缺失掩码和原生位串作 0 ULP 比较。缺失不补零，原 `finite_numeric_batch_passed=false`、`independent_review_completed=false` 等观察阶段标记保留。现在完成的独审在 [机器记录](f1-fi-sv-round14.json) 的 `independent_review` 单列，不倒签事前审查或扩大无记录外部查询的排除范围。
